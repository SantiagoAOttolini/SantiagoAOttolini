## About me

I'm a Software Engineer with over 7 years of experience building web applications for banking,
retail and e-commerce. Most of my career has been focused on frontend development with React and
TypeScript, working on large applications where maintainability, performance and long-term
scalability are essential.

More recently, I've been building AI-powered applications by integrating Large Language Models,
AI agents, RAG pipelines, Python (FastAPI), and modern AI workflows into production-ready
products. I enjoy solving complex engineering problems, improving developer experience, and
building software that teams can keep evolving over time.

Currently working at **Plexus IT**, building end-to-end features and AI integrations for
enterprise clients including **Santander Bank** and **INDITEX**.
